Path Follow in Blender

    一个用于 Blender 的路径跟随 / 放样插件：选中一条截面和一条（或多条）路径，一键沿路径扫掠生成放样模型，支持实时更新、拐角处理、路径映射等。

作者：Xbman
标注：本插件大量代码使用AI开发，具有学习价值与进步空间。

✨ 功能特性

    一键放样：选中截面 + 路径（路径为活动物体），直接生成挤出物。

    支持曲线与网格路径：CURVE 和 MESH 都可以作为路径。

    多路径批量生成：把截面设为活动物体，同时选中多条路径，一次性生成多个放样物体（每条路径一份独立可编辑截面）。

    实时更新（Live Update）：编辑路径或截面时，自动重建放样模型，无需重复点击生成。

    可编辑截面：生成后原截面可继续编辑，模型随之更新。

    撤销 / 重做保护：完整支持 Blender 的 Undo / Redo，避免状态错乱。

    拐角处理：

        拐角锐化（对称斜切，水密无缺口）

        拐角圆角（可设置分段数与半径比例）

        拐角角度阈值可调

    路径映射：可指定截面沿路径从 N% 到 M% 之间生成。

    截面控制：X/Y 轴镜像、90° 步进旋转、9 宫格对齐方式、Z 轴向上模式。

    路径控制：切换首尾方向、闭合路径、起始/结束正交（贴平到最近全局平面）。

    封口控制：起始封口、结束封口可独立开关。

    中英文界面：面板右上角可一键切换语言。

    方向箭头显示：编辑模式下显示路径放样的方向箭头。

📦 安装

    下载本仓库的 Path_Follow_in_Blender.py（或打包好的 .zip）。

    打开 Blender → 编辑 (Edit) → 偏好设置 (Preferences) → 插件 (Add-ons) → 安装 (Install…)。

    选择 .py 文件或 .zip 文件，安装后在列表里勾选 Path_Follow_in_Blender 启用。

    在 3D 视图 → 侧边栏（N 面板）→ Path Follow 标签页中打开主面板。

    兼容 Blender 2.80+（包含 3.x / 4.x）。推荐使用 3.6 LTS 或更新的版本。

🚀 快速开始

    在场景中创建一条截面（Mesh）和一条路径（Curve 或 Mesh）。

    先选中截面，再按住 Shift 选中路径（路径最后选中，成为活动物体）。

    打开侧边栏 Path Follow 面板。

    点击底部 执行路径跟随 按钮，即可生成放样物体（默认放入 挤出物 集合）。

生成完成后：

    若打开 实时更新，编辑路径或截面时模型会自动跟随重建。

    点击 应用物体（不再实时更新） 可断开关联，把放样物固定为普通网格。

🧭 面板说明
顶部（选中已生成的放样物时显示）
按钮	说明
选中路径	选中并激活该放样物关联的路径
选中截面	选中并激活该放样物关联的截面
应用物体	断开关联属性，停止自动更新
分段 / 实时更新

    分段（Segments）：曲线路径的重采样段数（几何节点 Resample Curve），仅曲线路径可用。

    实时更新（Live Update）：开启后编辑路径或截面会自动重建模型。

对齐（9 宫格）

用 ↖ ↑ ↗ / ← ⊙ → / ↙ ↓ ↘ 九个按钮，把截面的锚点对齐到路径起点。
变换

    X轴镜像 / Y轴镜像：按截面边界框中心镜像。

    ⟲ 90° / 90° ⟳：绕截面法线按 90° 步进旋转。

    ⇄ 切换路径首尾：反转路径方向。

    ⬆ 保持Z轴向上：强制截面 Z 轴朝向全局 Z 轴（避免路径扭曲）。

路径映射（Path Mapping）

    开始映射 / 结束映射：控制截面沿路径从 N% 到 M% 之间生成。

    重置映射：恢复为 0.0 ~ 1.0。

封口与拐角

    起始封口 / 结束封口：是否封闭放样两端。

    起始正交 / 结束正交：让首尾截面贴平到最近的全局平面。

    拐角锐化：在急拐角处生成水密锐边。

        角度：判定拐角的角度阈值（默认 30°）。

        拐角分段：>0 时拐角生成圆弧过渡（圆角），0 时关闭。

        圆角半径：圆角半径占较短邻段长度的比例。

    闭合路径：把路径首尾相连形成环路。

    截面吸附到路径：

        开启：原截面被移动到路径起点（兼容旧行为）。

        关闭（默认）：原截面保留在原位，放样使用其副本。

🔧 多路径批量生成

    选中多条路径 + 一条截面，并把截面设为活动物体。

    执行路径跟随，插件会为每条路径生成一份独立放样，并各自使用独立副本截面。

    生成后所有放样物会被自动选中，方便批量处理。

🖼️ 界面语言

在 偏好设置 → 插件 → Path Follow in Blender 中，或点击面板右上角的 🌐 按钮，可在 中文 / English 之间切换。
❓ 常见问题

Q：执行时提示「活动物体必须是原始路径 Mesh/Curve」？
A：请把路径设为活动物体（最后选中），同时保证截面为普通 Mesh（不是放样物、不是可编辑截面源）。

Q：多路径模式没反应？
A：多路径模式下请把截面设为活动物体，并至少选中 2 条路径。

Q：撤销后模型错乱？
A：插件内置撤销/重做守卫，会在撤销后自动排一次重建。若仍未恢复，可直接点击 执行路径跟随 手动重建。

Q：截面被消耗 / 消失了？
A：开启截面吸附到路径时，原截面会被移动到路径起点；关闭则保留原截面在原地，放样使用副本。

Q：生成太慢 / 抖动？
A：建议先关闭实时更新，调整参数完成后再开启。
